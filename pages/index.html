Forensic ML Challenge

Launch a reusable, browser-based forensic classification challenge powered by JupyterLite. Everything runs locally in the participant's browser with no server, login, or software install.

Launch participant notebook Open diagnostics notebook Browse the JupyterLite workspace

How participants use it

  • Open the notebook and run the setup cell to install browser-side Python packages.
  • Inspect the labelled training dataset in data/training_samples.csv.
  • Upload replacement CSV files in the left sidebar to swap in a new challenge.
  • Run the built-in model search to compare candidate classifiers.
  • Use the best model to classify the mystery samples and reveal the next clue label.
